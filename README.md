# Digital ASIC Full Flow

This repository documents a complete Digital ASIC Design & Implementation flow.

## Flow

Specification
→ RTL Design
→ Functional Verification
→ Logic Synthesis
→ DFT / Scan
→ Equivalence Check
→ Pre-layout STA
→ Floorplan
→ Placement
→ CTS
→ Routing
→ RC Extraction
→ Post-layout STA
→ Timing Closure
→ Final Verification

## Target
- Logic Synthesis
- STA
- Physical Implementation
- Physical Design
